# ADENDO AO PROMPT — METODOLOGIA DE ESTUDO BASEADA EM PRÁTICA

Existe uma informação MUITO importante sobre meu modelo de aprendizagem e você DEVE adaptar toda a trilha com base nisso.

---

# MEU MODELO DE APRENDIZAGEM

Eu NÃO aprendo bem apenas com teoria.

Meu aprendizado é fortemente baseado em:
- prática
- experimentação
- construção de projetos
- troubleshooting
- erros reais
- evolução iterativa

SQL, banco de dados, performance, tuning e infraestrutura só fazem sentido para mim quando eu vejo isso funcionando em um projeto real.

Portanto:

# A TRILHA DEVE SER:
- 80% prática
- 20% teoria

A teoria deve existir apenas para:
- criar fundamento
- explicar conceitos
- permitir aplicação prática

A prática deve ser o CENTRO da formação.

---

# ESTRUTURA SEMANAL QUE VOCÊ DEVE SEGUIR

- 5 horas semanais

A estrutura deve funcionar assim:

- objetiva
